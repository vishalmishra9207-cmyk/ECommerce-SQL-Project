# 🛒 E-Commerce SQL Analysis Project

## 📌 Project Overview
This project simulates an E-commerce database and performs advanced SQL analysis.

## 🗂 Database Schema
- customers
- products
- orders
- order_items

## 🔍 SQL Concepts Used
- Joins
- Group By & Having
- Subqueries
- Correlated Subqueries
- Window Functions
- CTE
- Ranking Functions
- NTILE
- User Access Control

## 📊 Key Insights
- Top 3 Customers by Revenue
- Best Selling Product
- Monthly Revenue Trends
- Category-wise Revenue
- Customer Segmentation

## 🔐 Access Control
Created read-only user using GRANT SELECT permission.
